## Suggested reading order

1. Read the project README and complete local setup.
2. Use the repository map to find the relevant application area.
3. Run the checks in TESTCMD.md that match your work.
4. Follow the contribution guide when opening an issue or pull request.
5. Use the backend and OTP deployment guides when configuring hosted services.
