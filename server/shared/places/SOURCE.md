# Philippine delivery localities

These locality names come from the Philippine Statistics Authority's Philippine Standard Geographic Code. The application groups the names for cascading address selectors. Metro Manila and region groups for independent cities serve as delivery areas where no province applies.

The directory uses the [June 2026 distribution](https://github.com/Tenasia/ph-psgc/tree/2026-Q2) of the PSA masterlist and incorporates the September 2026 correction of Lambagan in Cabanglasan, Bukidnon. It contains the locality names only. [PSA publication and attribution (CC BY 4.0)](https://psa.gov.ph/classification/psgc)
